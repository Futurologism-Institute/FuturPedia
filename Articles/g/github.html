GitHub

GitHub is a web-based platform for version control and collaborative software development using Git. It allows developers to host and review code, manage projects, and build software together.

The company was founded in 2008 by Tom Preston-Werner, Chris Wanstrath, and PJ Hyett. It quickly became the dominant platform for open-source and private software development. Microsoft acquired GitHub in 2018 for $7.5 billion.

Key features include repositories, pull requests, issues, Actions (CI/CD), Codespaces, and package hosting. GitHub hosts millions of projects and is a central part of modern software engineering workflows.
